# modules

Features e sistemas de gameplay modulares vivem aqui.

Cada módulo deve possuir responsabilidade clara, manifesto/dependências, contratos públicos, testes e documentação associada.

Exemplos futuros:

- combat
- abilities
- war
- factions
- quests
- economy
- building
- creatures
- taming
- professions
- crafting
- magic
- crime
- diplomacy

Módulos não devem acessar internals uns dos outros.
