# assets

Recursos visuais e sonoros do projeto.

## Planned categories

- characters/
- creatures/
- environment/
- buildings/
- equipment/
- ui/
- vfx/
- audio/

## Principles

- Visual principal: 2D vetorial/modular com rig e deformação.
- Assets devem considerar legibilidade mobile.
- Separar fonte/editável de export/runtime quando o pipeline for definido.
- Evitar duplicação desnecessária de assets para variações que podem ser feitas por composição, paleta, material ou parâmetros.
